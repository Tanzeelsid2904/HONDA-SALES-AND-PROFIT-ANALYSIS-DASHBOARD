# Honda Sales Analysis Dashboard | Power BI

## Project Overview

An interactive **Honda Sales Analysis Dashboard** developed using Microsoft Power BI to analyze sales, cost, and profitability across different cities, states, payment modes, and months.

The dashboard provides valuable business insights into sales performance, gross profit distribution, customer payment preferences, and monthly sales trends through interactive visualizations.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning & Transformation
- Data Visualization

## 📊 Key Performance Indicators (KPIs)
- **Gross Profit:** 11.84M
- **Net Sales Amount:** 53.04M
- **Total Cost Price:** 41.20M

## 📈 Dashboard Features

### 1. City-wise Gross Profit Analysis
- Compares gross profit across different cities.
- Identifies top-performing cities.
- Includes New Delhi, Surat, Lucknow, Noida, Ahmedabad, and Bangalore.

### 2. Payment Mode Analysis
- Analyzes net sales by payment mode.
- Compares UPI, Credit Card, Finance, and Cash transactions.

### 3. State-wise Net Sales Analysis
- Visualizes net sales distribution across different states.
- Includes Uttar Pradesh, Gujarat, Karnataka, Maharashtra, and Delhi.

### 4. Monthly Performance Analysis
- Tracks monthly gross profit.
- Analyzes monthly net sales.
- Compares monthly cost price trends.

## 🎯 Project Objectives
- Analyze overall Honda sales performance.
- Identify cities generating the highest gross profit.
- Understand state-wise sales distribution.
- Analyze customer payment preferences.
- 
- Track monthly sales and profitability trends.
- Convert raw sales data into meaningful business insights.
